## How we work

- **A written scope before any code.** Fixed price and deadline, approved by you before the first line.
- **An automated gate on every project.** Linting, type checking, unit tests, end-to-end tests, static analysis and secret scanning all run before anything ships.
- **No lock-in.** The code and the hosting stay with us while we look after your system, which is exactly what frees you from administering it. If you ever want to move to another vendor or to your own infrastructure, we hand over the code and the data and see the migration through.
- **One person accountable.** You talk to the person who writes the code, not to a first-level support queue.
