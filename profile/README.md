## O que construímos

- **Plataformas web e sistemas de gestão sob medida**, do painel interno ao produto que o seu cliente final usa.
- **Automação de processos** que hoje são feitos na mão, no WhatsApp ou na planilha.
- **Integração entre sistemas** que não conversam, incluindo ERP, gateway de pagamento e API de terceiro.
- **IA aplicada** a atendimento, a documento e a transcrição, com o resultado dentro do seu sistema e não num chat à parte.

Sistemas nossos rodam hoje em esporte, turismo, saúde, beleza, audiovisual e terceiro setor.

## Como trabalhamos

- **Escopo escrito antes do código.** Prazo e valor fechados, aprovados por você antes da primeira linha.
- **Portão automatizado em todo projeto.** Lint, checagem de tipo, teste unitário, teste de ponta a ponta, análise estática e varredura de segredo rodam antes de qualquer coisa subir.
- **Sem ficar preso.** O código e a hospedagem ficam com a gente enquanto cuidamos do seu sistema, que é o que faz você não administrar nada. Se um dia quiser levar para outro fornecedor ou para a sua infraestrutura, entregamos o código e os dados e acompanhamos a transferência.
- **Uma pessoa responsável.** Você fala com quem escreve o código, não com um atendimento de primeiro nível.

## Tecnologia

**Backend** C#, .NET 8 e 9, ASP.NET Core, Entity Framework Core, Razor Pages, Worker Services, microsserviços, APIs REST, Hangfire, Python e FastAPI

**Frontend** Next.js, React, TypeScript, Blazor, Tailwind CSS

**Banco e dados** PostgreSQL (com pgvector), SQL Server, SQLite, modelagem, tuning de query e análise de plano de execução

**IA aplicada** Claude (Anthropic), OpenAI, Azure OpenAI, LangChain, Semantic Kernel, RAG e busca semântica com embeddings, RPA, OCR e extração de documento, Deepgram para transcrição, ML.NET, scikit-learn e Pandas para previsão, recomendação e reinforcement learning

**Integração** WhatsApp Cloud API, gateways de pagamento e Stripe, APIs bancárias, Dynamics 365, Power BI, IoT, RabbitMQ, SignalR, webhooks

**Segurança e identidade** Entra ID, OIDC, JWT, baseline OWASP, criptografia, varredura de segredo

**Infraestrutura e operação** Azure, AWS, Docker, Coolify, Cloudflare, GitHub Actions, PostgreSQL com restauração a ponto no tempo, Application Insights, Sentry, Serilog

Essa lista é o que já foi para produção, não um cardápio. Se o seu problema pedir outra coisa, avaliamos e dizemos com franqueza se é o caminho certo.
